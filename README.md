# PromptVision AI

Frontend mobile-first do PromptVision AI.

Nesta fase, o projeto contém somente interface visual, navegação e dados simulados. Não há banco de dados, autenticação real, pagamentos ou integração com inteligência artificial.

## Tecnologias

- Next.js
- React
- TypeScript
- CSS responsivo

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Telas concluídas

- Landing Page
- Onboarding
- Login
- Cadastro

## Próxima tela

- Dashboard mobile

## Estratégia de desenvolvimento

As telas são construídas uma por vez, com componentes e estilos reutilizáveis, navegação visual e validação mobile entre 360px e 430px. A lógica real será conectada somente depois que toda a experiência visual estiver pronta.
