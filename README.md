# PromptVision AI

Frontend mobile-first do PromptVision AI.

Nesta fase, o projeto contém somente interface visual, navegação e dados simulados. Não há banco de dados, autenticação real, pagamentos ou integração com inteligência artificial.

## Tecnologias

- Next.js
- React
- TypeScript
- CSS responsivo

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Estratégia de desenvolvimento

As telas são construídas uma por vez, com componentes reutilizáveis e validação mobile entre 360px e 430px.

## Telas concluídas

- Landing Page mobile
- Onboarding mobile
